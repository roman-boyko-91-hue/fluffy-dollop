# Проект "Рефакторинг веб-приложения"

## Описание:

Проект "Рефакторинг веб-приложения" - это веб-приложение на Python в рамках 
домашнего задания №25.

## Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/roman-boyko-91-hue/fluffy-dollop
```

2. Установите зависимости:

```
pip install -r requirements.txt
```

3. Запустите локальный сервер:

```
python manage.py runserver
```

## Использование:

1. Перейдите на страницу в вашем веб-браузере.
