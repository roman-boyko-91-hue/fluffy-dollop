# Проект "Веб-приложение"

## Описание:

Проект "Веб-приложения" - это курсовая работа над 
веб-приложением на Python в рамках курса 7. 

## Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/roman-boyko-91-hue/fluffy-dollop
```

2. Установите зависимости:

```
pip install -r requirements.txt
```

3. Установите библиотеку Redis:

```
pip install Redis
```

4. Запустите локальный сервер:

```
python manage.py runserver
```

## Использование:

1. Перейдите на страницу в вашем веб-браузере.
