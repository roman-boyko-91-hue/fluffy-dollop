# Проект Homework_17_1

## Описание:

Проект Homework_17_1 - это проект домашнего задания
в рамках 4 курса Разработка на Python

## Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/roman-boyko-91-hue/Repository/tree/feature/homework_14_1
```

2. Установите зависимости:

```
poetry install
```

3. Установите фреймворк pytest через Poetry

```
poetry add --group dev pytest
```

## Использование

1. Откройте файл `product.py`.
2. Проверьте работу исключений класса `Product`.
3. Откройте файл `category.py`.
4. Проверьте работу исключений класса `Category`.
3. Откройте модуль `tests`.
4. Запустите тестирование функции через `pytest`.
