# Проект Homework_16_1

## Описание:

Проект Homework_16_1 - это проект домашнего задания
в рамках 4 курса Разработка на Python

## Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/roman-boyko-91-hue/Repository/tree/feature/homework_14_1
```

2. Установите зависимости:

```
poetry install
```

3. Установите фреймворк pytest через Poetry

```
poetry add --group dev pytest
```

## Использование

1. Откройте файл `smartphone.py`.
2. Проверьте работу новой функциональности класса `Smartphone`.
3. Откройте файл `lawngrass.py`.
4. Проверьте работу новой функциональности класса `LawnGrass`.
5. Откройте модуль `tests`.
6. Запустите тестирование функции через `pytest`.
