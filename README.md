# Проект Курсовая 2

## Описание:

Проект Курсовая - это проект курсовой работы
в рамках 4 курса Разработка на Python

## Установка:

1. Клонируйте репозиторий:

```
git clone https://ghttps://github.com/roman-boyko-91-hue/fluffy-dollop/tree/coursework_2
```

2. Установите зависимости:

```
poetry install
```

3. Установите фреймворк pytest через Poetry

```
poetry add --group dev pytest
```

## Использование

1. Откройте модуль `src`.
2. Проверьте работу функций.
3. Откройте модуль `tests`.
4. Запустите тестирование функции через `pytest`.
