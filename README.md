# Проект Курсовая

## Описание:

Проект Курсовая - это проект курсовой
в рамках 3 курса Библиотеки для Python разработчика

## Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/roman-boyko-91-hue/fluffy-dollop/tree/coursework_1
```

2. Установите зависимости:

```
poetry install
```

3. Установите фреймворк pytest через Poetry

```
poetry add --group dev pytest
```

4. Установите библиотеку `pandas`

```
poetry add pandas
```

## Использование

1. Откройте файл `main.py`.
2. Проверьте работу программы `main`.
3. Откройте модуль `tests`.
4. Запустите тестирование, находящихся в модуле функций через `pytest`.
